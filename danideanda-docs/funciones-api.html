Funciones API

La API de api.danidenada.dev es de solo lectura. No ejecuta comandos del sistema ni acepta rutas indicadas por el cliente.

autenticación

Los comandos administrativos requieren la cabecera X-API-Key. Si falta o no coincide, el servidor responde 404, igual que si el recurso no existiera.

curl -X POST https://api.danidenada.dev/api \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: TU_CLAVE' \
  -d '{"command":"monitor"}'

comandos disponibles

ComandoRespuesta
estadoEstado del proceso y tiempo de actividad.
horaHora actual en UTC.
versionVersión de Python en uso.
monitorUptime, carga, memoria, disco y métricas del proceso.
securityLogins SSH fallidos, configuración sshd, permisos de secretos, puertos en escucha y reinicio pendiente.

login de cursos

POST /api/login valida usuario y contraseña y devuelve un token firmado con caducidad de 12 horas.

curl -X POST https://api.danidenada.dev/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"alumno","password":"..."}'

Credenciales incorrectas, usuario inexistente o token inválido responden siempre 404.
